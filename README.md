## 🧬 About Me

I'm **Bharathkrishna**, a cybersecurity enthusiast focused on the intersection of **offensive security, networking, embedded systems, and automation**.

My playground isn't limited to software. I like going all the way down the stack:

```text
APPLICATION
     ↓
NETWORK
     ↓
OPERATING SYSTEM
     ↓
HARDWARE
     ↓
SIGNALS
     ↓
PROTOCOLS
     ↓
"WHY DOES THIS WORK?"
```

I'm particularly interested in understanding how systems communicate, where they break, how they can be secured, and how hardware can be turned into practical security tools.
